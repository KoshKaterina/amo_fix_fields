# Выкатка записи оплаты в заказ МС (PR Sunscrypt/amo_fix_fields#25), режим сухого прогона

Инструкция для ЛОКАЛЬНОЙ сессии Claude Code на компьютере Кати (там есть ssh-ключ прод-сервера и
рабочая папка с `LOCKS.md`). Облачная сессия, которая писала код, доступа к серверу не имеет.

**Разрешено «го» Кати 05.11.2026:** выкатить код и включить оба режима В СУХОМ ПРОГОНЕ.
**Не разрешено:** боевой режим (`*_DRY_RUN=0`), слияние PR, любые другие правки на проде.

Что выкатывается: оплата Ozon и оплата при выдаче (самовывоз из офиса, наложка в «Успешно реализовано»
Офиса) записываются в заказ МС входящим платежом. Подробности и правила - раздел «Оплата -> платёж в заказе МС»
в `AGENTS.md`. В сухом прогоне код только ЧИТАЕТ МС и пишет в лог «создал бы платёж»: ни платежей, ни
примечаний в амо, ни сообщений в Телеграм, ни очереди.

## Красные линии (из `AGENTS.md`)

- Перед любым действием на проде прочитать `LOCKS.md` рабочей папки и взять локи: **выкатка**, **правка `.env`**,
  **рестарт контейнеров**. Снять после окончания.
- **`.env` не читать, не выводить, не коммитить.** Проверять наличие переменной только счётчиком
  (`grep -c`), добавлять только дописыванием в конец.
- Прод бывает ВПЕРЕДИ локальной копии: каждый изменяемый файл сверить с сервером по md5 ДО заливки.
  Переводы строк различием не считать (часть файлов на проде с CRLF): перед md5 убрать `\r` с обеих сторон.
- Пересборка контейнера роняет вебхуки амо в 502 на время сборки, повторов от амо ждать нельзя. Прочитать
  `knowledge/vebhuki-teryayutsya-pri-peresborke-amo-fix-fields.md` рабочей папки, выбрать способ и согласовать
  момент с Катей до пересборки.
- ssh/scp запускать через PowerShell (ключ с фразой в ssh-agent Windows, в Git Bash ssh агента не видит).
  Длинные команды не писать инлайном: сложить скрипт в файл, `scp` на сервер, там
  `sed -i 's/\r$//' /tmp/x.sh && sudo bash /tmp/x.sh`. Шагов в один скрипт класть побольше: каждое отдельное
  подключение - риск fail2ban.

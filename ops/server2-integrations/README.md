## Что не в git

`/opt/integrations/.env` (права 600) - из него override берёт две переменные:
- `MS_PROXY_URL` - адрес шлюза `82.97.249.88:18080` с логином и паролем;
- `MS_NO_PROXY` - адреса, которые ходят мимо шлюза: петля, соседние контейнеры, панель, amo, СДЭК, Wazzup,
  Метрика, Озон и прочие API.

Телеграм-бот `amo-fix-fields` берёт свой прокси из другой переменной, `TG_PROXY_URL` в
`/opt/integrations/amo_fix_fields/.env`. Override его не касается.

## Выкатка правки

1. Бэкап: `cp -p docker-compose.override.yml docker-compose.override.yml.bak-<что>-<дата>`.
2. Проверить сборку: `docker compose config | grep -E '^  [a-z0-9-]+:$|NO_PROXY'`.
3. Пересоздать только нужный контейнер, без пересборки и без соседей:
   `docker compose up -d --no-build --no-deps --force-recreate <сервис>`.
4. ⚠️ `amo-fix-fields` пересоздавать только при живом шлюзе: Телеграм-бот один раз на старте проверяет связь,
   не дозвонился - выключается до следующего рестарта. Проверять Телеграм через прокси `curl -x` или
   `aiohttp`, не `urllib` - у него на этом прокси ложный отказ.
